PERSONAL DEVELOPER PORTFOLIO - CLEAN STARTER
=============================================

This is a fresh portfolio starter. It does not include any of your previous
projects or assume your previous work history.

FILES
-----
index.html  - Website structure and editable placeholder content
style.css   - Responsive dark theme styling
script.js   - Mobile menu, scroll reveal, year and contact email behavior

RUN ON WINDOWS
--------------
1. Extract the ZIP file.
2. Open the developer-portfolio folder in VS Code.
3. Open index.html with Live Server, or double-click index.html.

CUSTOMIZE WHEN READY
--------------------
- Review your name, education, and introduction.
- Update the skills list as your experience grows; it currently reflects the planned learning roadmap.
- Replace Project One, Two, and Three only after you create those projects.
- Add a resume link when your resume is ready.
- No LinkedIn profile is displayed.

The contact form currently opens a pre-filled email in the visitor's email app.
It does not store messages on a server.

This is only the initial static frontend. Authentication, OAuth, MFA, database,
Docker, AWS, Kubernetes, Terraform, Ansible, Grafana, ELK, and Cloudflare
will be added in later project phases.
